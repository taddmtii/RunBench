# RunBench

A personal coding practice platform for solving algorithm problems in the browser. Pick a problem, write a solution, run it against a test suite, and track your progress and runtime performance over time.

> **Status:** Work in progress.

## Features

- **In-browser editor**: solve algorithm problems without leaving the page
- **Automated test suites**: submissions run against test cases with pass/fail results
- **Solve history**: every submission is recorded
- **Runtime tracking**: compare execution times across attempts
- **AI problem creation**: generates everything a problem needs, so there's less manual input
- **AI code analysis**: after submitting, get your solution's time and space complexity along with the reasoning behind it
- *WIP:* progress stats and dashboards
- *WIP:* additional languages and problem sets
